### プロジェクトのセットアップ方法

1. Firebaseコンソールから `GoogleService-Info.plist` ファイルを取得するか、チームメンバーからファイルを共有してもらってください。
2. プロジェクトルート（`TwitterSwiftUITutorial/`ディレクトリ）に `GoogleService-Info.plist` を配置します。
3. その後、Xcodeでプロジェクトを開き、ビルドしてください。

注意: `.gitignore`で `GoogleService-Info.plist` ファイルが無視されているため、直接リポジトリには含まれていません。
